Ditto is an open-source, decentralized social media client built on the [Nostr](https://nostr.com/) protocol. It's a fun, customizable client with theming, Lightning payments, and an ever-growing set of content types (text notes, articles, short-form videos, live streams, polls, and more) — all while owning your identity and data.

Ditto builds to static files (no backend, no database) and connects directly to Nostr relays from the browser.
